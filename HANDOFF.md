## 3. Известные ограничения и риски

### Контент
1. **Контент написан AI и не вычитан преподавателем.** Рассказы, 40 тем грамматики (592 упражнения), тесты и переводы словарей
   проверены автоматически (формат, «правильный ответ действительно засчитывается»), но **не человеком-экспертом**.
   Возможны: неточный перевод, неоднозначный вопрос (два ответа подходят), неестественная фраза.
   → Если встретите ошибку — исправьте JSON/CSV и запустите `validate_content.py` + `build_site_data.py`. Желательно выборочно показать преподавателю B1-темы.
2. **Подсветка слов — автоматическая.** Слово, совпадающее со словарным по форме, отмечается всегда, даже если в тексте другое значение.
   Поэтому показываются **все** значения формы. Имя в начале предложения (*Mark went…*) может отметиться как слово *mark*.
3. **Задание «вставьте слово»** собирается автоматически: иногда неправильный вариант тоже может грамматически подойти.
4. **Рассказы 21–40 без mp3** (так решили): читает голос браузера, его качество зависит от устройства.

### Диктант
- Цифры и слова считаются одинаковыми (`25` = `twenty-five`), но:
  - годы читаются как числа: `1999` = «one thousand nine hundred ninety nine», а не «nineteen ninety-nine»;
  - порядковые (`25th`), сокращения (`it's` ≠ `it is`), британское/американское написание (`colour` ≠ `color`) считаются ошибкой.

### Прогресс
- **Прогресс хранится в браузере и привязан к адресу сайта.** `localhost:5173`, `192.168.1.5:5173` и `172.20.10.2:5173` — для браузера
  **три разных сайта** с разным прогрессом. Если у компьютера в сети сменится IP (другой Wi-Fi, точка доступа), на телефоне прогресс «пропадёт»
  (он останется по старому адресу). **Решение:** резервная копия в файл — сохраните на старом адресе, загрузите на новом. После деплоя адрес станет постоянным.
- В списке слов статус меняется кнопками «учу» / «выучено» (в фильтрах «Новые», «Учу», «Выучено»); история повторений при этом **не удаляется**.
  Вернуть слово в «новое» из интерфейса нельзя (и не нужно).
- Очистка данных браузера удаляет весь прогресс — делайте резервную копию в файл время от времени (автоматической нет).

### Техника
- **Данные сайта (`web/public/data`) лежат в git и генерируются.** Если изменить контент и забыть `build_site_data.py`, сайт покажет старые данные.
  CI пересобирает данные перед тестами, но **не проверяет**, что в репозитории они актуальны. → Совет 9.
- **Тесты в браузере завязаны на контент** (например: в A2 ровно 906 слов, первое предложение диктанта рассказа 01 — «Anna is twenty-five years old»).
  Если изменить эти данные, тесты упадут — это нормально, их нужно обновить вместе с контентом.
- **edge-tts** (озвучка) — неофициальный доступ к голосам Microsoft. Может перестать работать без предупреждения; готовые mp3 это не затронет.
- **`npm audit`**: уязвимость `picomatch` (ReDoS) в инструментах сборки, на сайт не попадает, исправления пока нет. Остальное устранено.
- **mp3 больше не в git** (с 2026-11-20 — Supabase Storage). Старые коммиты всё ещё содержат ≈ 115 МБ; уменьшить — только переписав историю (не делали).
- **Supabase Free:** трафик 5 ГБ/мес; проект засыпает после недели без активности → mp3 на сайте перестанут играть (рассказы перейдут на голос браузера). Против этого — `keep-supabase-awake.yml`.
- **Новые mp3 не попадут на сайт сами:** после `make_story_audio.py` / `make_word_audio.py` — `build_site_data.py` и `upload_audio.py`. Если забыть загрузку, плеер будет пустым (`build_site_data.py` предупредит «⚠ Нет mp3», только если mp3 нет на диске).
- **Ключи AI** — в секретах Worker'а, браузер их не видит; `/api/ai` работает только после входа по коду.
  Свои ключи в браузере остались запасным вариантом (они видны в инструментах разработчика).
  Не вписывать ключ в код и в `.env` сайта — после сборки он окажется в открытых файлах сайта.
- **Ключ Gemini и код доступа попали в чат с Claude (2026-11-19)** — пользователю: создать новый ключ Gemini, удалить старый; сменить код в `ACCESS_CODES`. Ключ Groq, засветившийся раньше, тоже заменить, если это не сделано.
- **Секреты — только через обычный Терминал**: `npx wrangler secret put ИМЯ` ждёт ввода, через `!` в чате с Claude значение не передаётся (так в секрете оказался неверный ключ Groq). Проверить, какие секреты есть: `npx wrangler secret list` (только имена).
- **Бесплатный Gemini нестабилен**: модели бывают перегружены (503) или «зависают»; при смене моделей Google проверить `…/api/ai/check` и при необходимости задать `GEMINI_MODEL`.
- **Лимита AI на человека пока нет** (будет с D1): вошедший по коду может делать запросы без ограничений в пределах лимитов Gemini/Groq. То же для озвучки `/api/tts`.
- **Озвучка edge-tts в Worker'е — неофициальный доступ, и его придётся поддерживать.** Microsoft периодически меняет токен `Sec-MS-GEC`
  (в 2026 перешёл на v2 — запутанный хеш). Тогда `/api/tts` начнёт отвечать «Сервис озвучки не принял соединение (HTTP 403)».
  Как чинить: `pip install -U edge-tts` → перенести изменения `edge_tts/drm.py` и `constants.py` в `web/worker/edgeTts/drm.ts`
  (константы генерируются скриптом — см. шапку файла) → обновить эталоны в `drm.test.ts`. Готовые mp3 на устройствах это не затрагивает.
- **mp3 «Моих слов» не входят в резервную копию** (только слова): после очистки браузера их нужно пересоздать кнопкой.
- **Сам сайт открыт всем** (уроки, mp3) — закрыты кодом только AI и (в будущем) прогресс.

Решения и риски:
- **История git не уменьшится** (старые 115 МБ останутся в прошлых коммитах). Уменьшить можно только переписав историю (`git filter-repo` + force push) — опасно, отдельное решение пользователя; пока не делаем.
- Трафик: средний mp3 ≈ 1.4 МБ; 5 человек × 3 прослушивания в день ≈ 0.6 ГБ/мес — в пределах 5 ГБ. Сейчас Cloudflare отдаёт mp3 без лимита, после переезда лимит появится.
- Откат: вернуть `npm run build:pages` с копированием mp3 из папки `audio/` (mp3 на компьютере остаются).

# запуск

cd EL
python3 tools/validate_content.py
python3 tools/build_site_data.py
