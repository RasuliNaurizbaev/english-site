## 3. Известные ограничения и риски

### Контент
1. **Контент написан AI и не вычитан преподавателем.** Рассказы, 40 тем грамматики (592 упражнения), тесты и переводы словарей
   проверены автоматически (формат, «правильный ответ действительно засчитывается»), но **не человеком-экспертом**.
   Возможны: неточный перевод, неоднозначный вопрос (два ответа подходят), неестественная фраза.
   → Если встретите ошибку — исправьте JSON/CSV и запустите `validate_content.py` + `build_site_data.py`. Желательно выборочно показать преподавателю B1-темы.
2. **Подсветка слов — автоматическая.** Слово, совпадающее со словарным по форме, отмечается всегда, даже если в тексте другое значение.
   Поэтому показываются **все** значения формы. Имя в начале предложения (*Mark went…*) может отметиться как слово *mark*.
3. **Задание «вставьте слово»** собирается автоматически: иногда неправильный вариант тоже может грамматически подойти.
4. **Рассказы 21–40 без mp3** (так решили): читает голос браузера, его качество зависит от устройства.

### Диктант
- Цифры и слова считаются одинаковыми (`25` = `twenty-five`), но:
  - годы читаются как числа: `1999` = «one thousand nine hundred ninety nine», а не «nineteen ninety-nine»;
  - порядковые (`25th`), сокращения (`it's` ≠ `it is`), британское/американское написание (`colour` ≠ `color`) считаются ошибкой.

### Прогресс
- **Прогресс хранится в браузере и привязан к адресу сайта.** `localhost:5173`, `192.168.1.5:5173` и `172.20.10.2:5173` — для браузера
  **три разных сайта** с разным прогрессом. Если у компьютера в сети сменится IP (другой Wi-Fi, точка доступа), на телефоне прогресс «пропадёт»
  (он останется по старому адресу). **Решение:** резервная копия в файл — сохраните на старом адресе, загрузите на новом. После деплоя адрес станет постоянным.
- В списке слов статус меняется кнопками «учу» / «выучено» (в фильтрах «Новые», «Учу», «Выучено»); история повторений при этом **не удаляется**.
  Вернуть слово в «новое» из интерфейса нельзя (и не нужно).
- Очистка данных браузера удаляет весь прогресс — делайте резервную копию в файл время от времени (автоматической нет).

### Техника
- **Данные сайта (`web/public/data`) лежат в git и генерируются.** Если изменить контент и забыть `build_site_data.py`, сайт покажет старые данные.
  CI пересобирает данные перед тестами, но **не проверяет**, что в репозитории они актуальны. → Совет 9.
- **Тесты в браузере завязаны на контент** (например: в A2 ровно 906 слов, первое предложение диктанта рассказа 01 — «Anna is twenty-five years old»).
  Если изменить эти данные, тесты упадут — это нормально, их нужно обновить вместе с контентом.
- **edge-tts** (озвучка) — неофициальный доступ к голосам Microsoft. Может перестать работать без предупреждения; готовые mp3 это не затронет.
- **`npm audit`**: уязвимость `picomatch` (ReDoS) в инструментах сборки, на сайт не попадает, исправления пока нет. Остальное устранено.
- **Размер репозитория** ≈ 115 МБ из-за mp3. Каждая перезапись аудио увеличивает историю git.
- **Ключ AI виден в браузере** (запрос идёт напрямую). Для личного сайта нормально; для публичного — нужен сервер-посредник
  (бесплатно: Cloudflare Pages Functions / Workers, Netlify Functions, Vercel Functions, Deno Deploy, Supabase Edge Functions).
  Не вписывать ключ в код и в `.env` сайта — после сборки он окажется в открытых файлах сайта.

## 5. Советы (по приоритету)

### Сначала — деплой (текущая задача)
1. `git push origin development` → Pull Request `development` → `main` → merge (нужен `web/wrangler.jsonc` в `main`).
2. Cloudflare: **Create → Worker → Import a repository** → `En`; имя `open-english-for-beginner`, Root directory `web`,
   Build command `npm run build:pages`, Deploy command — по умолчанию (подробно — README → «Деплой»).
3. Проверить сайт на телефоне: рассказ 01 (mp3, караоке, перемотка в Safari на iPhone), рассказ 21 (голос браузера), «Слова», диктант.
4. **Пройти тест уровня** и **сохранить первую резервную копию прогресса** (прогресс на `*.workers.dev` — отдельный от `localhost`; перенос — через файл).

### Затем — дорожная карта
6. **AI-ключ через посредника** (на `development`): скрипт Worker'а (`main` в `wrangler.jsonc`) отвечает на `/api/ai/…`, остальное — статические файлы;
   ключ Gemini/Groq — в секретах Worker'а (Settings → Variables and Secrets или `npx wrangler secret put`), не в коде и не в `.env` сайта. Сайт обращается к `/api/ai/…`, ключ в браузер не попадает.
   Обязательно защитить посредника (иначе любой, кто знает адрес, тратит ваш лимит): Cloudflare Access на сайт или общий пароль/токен.
   Лимит на бесплатном плане — 100 000 запросов к коду Worker'а в день (запросы к статическим файлам сюда не входят).
7. **Улучшение кода**: обновление логики, архитектуры; отдельные сервисы — по необходимости (сейчас сайт статический, сервер нужен только для AI).
8. **PWA** после деплоя: иконка на телефоне, офлайн-режим.

### Улучшения учёбы (по мере занятий)
8. **Говорение** — самое слабое место сайта. Сейчас есть пересказ вслух и «пауза для повтора». Можно добавить запись своего голоса
   и сравнение с диктором (после деплоя по https микрофон станет доступен на телефоне). Но главное — живая практика:
   разговорный клуб, репетитор или языковой партнёр хотя бы раз в неделю.
9. **Письмо**: темы для писем и эссе уровня B1 с проверкой через тот же AI (Gemini/Groq) — логичное продолжение заготовки AI.
10. **Слова в контексте**: при повторении карточки показывать предложение из рассказа, где встретилось слово.
11. **Статистика**: календарь занятий, график выученных слов по неделям, время занятий.

### Технические
12. **CI: проверка актуальности данных** — после `build_site_data.py` выполнить `git diff --exit-code web/public/data`,
    чтобы проверка падала, если данные в репозитории устарели.
13. **Защита ветки `main`** на GitHub: merge только через Pull Request и только при зелёной проверке.
14. ~~Резервная копия прогресса~~ — сделано.

## 6. Рекомендуемый режим занятий (30–40 минут в день)

| Время | Что | Где на сайте |
|---|---|---|
| 10 мин | повторение слов + 10 новых | Сегодня → Слова |
| 10–15 мин | рассказ: послушать с караоке, прочитать, задания; раз в неделю — диктант | Рассказы |
| 10 мин | одна тема грамматики (или «Мои ошибки») | Грамматика / Практика |
| по желанию | mp3 со словами (в дороге), 10 глаголов | Аудио / Практика |
| раз в 1–2 месяца | пробный экзамен B1 или новый тест от AI | Практика → Тесты |

Ориентиры на год: месяцы 1–3 — рассказы 01–20 и грамматика A2; 4–9 — рассказы 21–40 и грамматика B1; 10–12 — пробные экзамены,
письмо и говорение. Плюс живая разговорная практика и с середины года — подкасты/сериалы с английскими субтитрами.

## 7. Полезные команды (шпаргалка)

```bash
# запуск
cd EL/web && npm run dev                       # компьютер + адрес для телефона

# после любых изменений контента
cd EL
python3 tools/validate_content.py
python3 tools/build_site_data.py

# полная проверка
cd EL/web && npm run check

# новые слова в рассказах / аудио
python3 tools/find_story_words.py --force
python3 tools/make_story_audio.py --only 21    # mp3 для одного рассказа (нужны edge-tts и ffmpeg)

# сборка для Cloudflare Worker (сайт + mp3 в web/dist) и проверка настроек
cd EL/web && npm run build:pages && npx wrangler deploy --dry-run

# git (push — вручную); деплой — merge development → main
git push -u origin development
```
