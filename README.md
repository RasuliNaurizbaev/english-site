# English — личный сайт для изучения английского (A1 → B1)

Сайт для ежедневных занятий английским: рассказы с аудио и караоке-подсветкой, интервальное повторение слов,
грамматика с подробными объяснениями и упражнениями, тесты уровня, диктант, неправильные глаголы и mp3 со словами.

- **Цель:** уверенный уровень B1 примерно за год при занятиях 30–40 минут в день.
- **Для кого:** русскоязычный ученик; все объяснения, подсказки и интерфейс — на русском.
- **Где работает:** на компьютере и на телефоне (в браузере), без интернета (кроме генерации тестов через AI).

## Разделы сайта и как ими пользоваться

Вкладки вверху: **Сегодня · Рассказы · Слова · Грамматика · Практика · Аудио**.

### ☀️ Сегодня
Главная страница — план на день:
- **Слова** — сколько карточек повторить и сколько новых слов взять сегодня;
- **Рассказ** — выберите уровень **A2** (рассказы 01–20) или **B1** (21–40) — откроется случайный рассказ этого уровня
  (сначала из непройденных). Нажмите уровень ещё раз — другой случайный рассказ. Выбор запоминается до конца дня;
- **Грамматика** — следующая неизученная тема;
- **Мои ошибки** — появляется, только если есть что повторить;
- **Слушать слова** (по желанию) — следующая непрослушанная часть mp3.

Ниже — серия дней подряд 🔥, полоски активности за неделю, прогресс по словам A1/A2/B1 и настройки:
сколько новых слов в день (5–30) и из каких уровней их брать.
В самом низу — **💾 Резервная копия прогресса**: «Сохранить в файл» (`english-progress-ГГГГ-ММ-ДД.json`) и «Загрузить из файла»
(перед заменой показывает, что в файле, и просит подтвердить). Ключи AI в файл не попадают.

### 🔁 Повторение слов (интервальное, как в Anki)
Открывается из «Сегодня» или «Слова». Карточка: слово → нажмите, чтобы увидеть перевод → оцените себя:

| Кнопка | Когда нажимать | Что будет |
|---|---|---|
| **Снова** | не вспомнил | слово покажется ещё раз через пару карточек (сегодня) |
| **Трудно** | вспомнил с трудом | новое слово — завтра; дальше интервал растёт немного |
| **Хорошо** | вспомнил | новое слово — через неделю; дальше интервал × «лёгкость» |
| **Легко** | сразу | новое слово — через 4 недели (сразу «выучено»); дальше интервал растёт сильнее |
| **Я это уже знаю** | для нового знакомого слова | сразу «выучено», следующий показ через 60 дней, не тратит лимит новых слов; над карточкой появится «✓ … → выучено» |

После «Снова» слово учится заново маленькими шагами (завтра → 3 дня → …).

Слово считается **выученным**, когда интервал доходит до 21 дня. Направление можно переключить: EN → RU или RU → EN.
Клавиши на компьютере: пробел — показать перевод, 1/2/3/4 — оценки.

### 📖 Рассказы
- Словарные слова подсвечены цветом уровня (A1 — зелёный пунктир, A2 — оранжевый, B1 — фиолетовый).
  Нажмите на слово — появится перевод. **У одной формы может быть несколько значений**
  (*left* — «левый» и прошедшее время от *to leave*) — показываются все.
- **Аудио** (плеер внизу экрана): выбор голоса, скорость 0.75× / 1× / 1.25×,
  **караоке** (подсветка звучащего предложения), **«Пауза для повтора»** (после каждого предложения — пауза, чтобы повторить вслух).
  Нажмите на предложение — оно зазвучит.
- **Голос браузера:** если у рассказа нет mp3 (21–40), mp3 не загрузился или плеер не работает —
  рассказ читает встроенный голос браузера (кнопки ▶ / ⏸ / ■), караоке тоже работает.
- В шапке: размер шрифта A− / A+, переключатели «Подсветка» и «Перевод».
- Под текстом:
  - **➕ Добавить новые слова рассказа в повторение** — слова сразу попадают в сегодняшние карточки;
  - **✍️ Диктант по рассказу**;
  - **Задания:** вопросы по тексту → «вставьте пропущенное слово» → план пересказа вслух.
    Когда отвечены все — рассказ отмечается пройденным с результатом в процентах.

### 🗂 Слова
Словарь по уровням A1 / A2 / B1: поиск по-английски и по-русски, фильтр «Все / Новые / Учу / Выучено».
Показывается **по 100 слов**: кнопка «Ещё 100 →» заменяет текущую сотню следующей, «← Назад» — предыдущей.
Строка слова: 🔊 · слово · перевод · справа статус или кнопки.
🔊 — голос устройства: сайт сам выбирает лучший английский голос (улучшенные Premium/Enhanced, Samantha, Google US English…)
и пропускает «шуточные» голоса macOS.

| Фильтр | Справа | Что делают кнопки |
|---|---|---|
| Все | только статус (новое / учу / выучено) | — |
| Новые | **учу** и **выучено** | «учу» — слово попадает в повторение уже сегодня (не тратит лимит новых); «выучено» — показ через 60 дней |
| Учу | **выучено** | |
| Выучено | **учу** | слово снова в повторении сегодня, учится заново маленькими шагами |

### 📐 Грамматика
40 тем по порядку A1 → A2 → B1. В каждой теме:
- подробное объяснение на русском: когда используем, как образуется (таблицы), слова-подсказки, сравнение с похожими формами;
- примеры с переводом и кнопкой 🔊;
- **типичные ошибки** (неправильно → правильно) и советы;
- 12–15 упражнений трёх видов: выбор варианта, вписать слово, собрать предложение из слов.

Тема считается **изученной при 80%** и выше. Ошибки из упражнений автоматически попадают в «Мои ошибки».

### 🎯 Практика
- **Тесты:** тест уровня (с A1 до B1, ~25 минут) и 3 пробных экзамена B1 (~45 минут: грамматика, лексика, чтение, аудирование).
  Аудирование читает голос браузера (текст можно открыть). Итог — процент и уровень; есть история результатов.
  Плюс **новые тесты от AI** (см. ниже).
- **Мои ошибки:** упражнения грамматики, где была ошибка, возвращаются через **1 → 3 → 7 → 14 дней**.
  Четыре верных ответа подряд — ошибка исправлена и исчезает; ошибка при повторении — снова через день.
- **Неправильные глаголы:** тренировка по 10 глаголов (сначала те, где чаще ошибались, и новые) — впишите 2-ю и 3-ю формы;
  принимается любой из вариантов (*learned / learnt*). Есть таблица с поиском и статистикой ✓/✗. Уровни глаголов выбираются.
- **Диктант:** 10 предложений из выбранного рассказа. Слушаете (можно «🐢 медленно» и сколько угодно раз) → пишете → проверка по словам:
  верные слова зелёные, ошибки подчёркнуты, лишние слова показаны отдельно.
  Регистр и знаки препинания не важны; **цифры = слова** (`25` = `twenty-five` = `twenty five`).

### 🎧 Аудио
mp3 со словами по уровням, по ~100 слов в файле: «Level A1. Part 1.», затем слово → пауза, чтобы повторить вслух.
Играет одна часть; когда она закончилась — отмечается «прослушано» и включается следующая.

## Быстрый старт

**Нужно:** Node.js (проверено на 24, в CI — 22) и Python 3.

### Первый запуск (например, на новом компьютере)
```bash
cd EL
python3 tools/build_site_data.py   # данные сайта: web/public/data/*.json (они уже есть в git, но так надёжнее)
cd web
npm install                        # библиотеки
```

### Каждый день
```bash
cd EL/web
npm run dev
```
Vite покажет адреса:
```
➜  Local:   http://localhost:5173/          ← на компьютере
➜  Network: http://192.168.x.x:5173/        ← на телефоне (та же сеть)
```

### Готовая сборка (как на сервере)
```bash
npm run build        # проверка типов + сборка в web/dist/
npm run preview      # открыть сборку (тоже показывает адрес для телефона)
```

### Все команды `web/`

| Команда | Что делает |
|---|---|
| `npm run dev` | режим разработки, изменения видны сразу, доступен с телефона |
| `npm run build` | проверка типов + сборка в `web/dist/` |
| `npm run preview` | открыть собранный сайт |
| `npm run typecheck` | проверка типов TypeScript |
| `npm test` | модульные тесты (Vitest) |
| `npm run test:e2e` | тесты в настоящем браузере (Playwright) |
| `npm run check` | всё вместе: типы → модульные тесты → сборка → тесты в браузере |

## Как открыть на телефоне

Сайт запускается на компьютере, телефон открывает его по сети.

1. Компьютер и телефон — **в одной сети**: общий Wi-Fi **или точка доступа с телефона**
   (iPhone: Настройки → Режим модема; Android: Настройки → Точка доступа), к которой подключён компьютер.
2. На компьютере: `cd EL/web && npm run dev`.
3. На телефоне откройте адрес из строки `Network:` (при раздаче с iPhone обычно `http://172.20.10.x:5173/`, с Android — `http://192.168.x.x:5173/`).
4. Удобно: Safari → «Поделиться» → «На экран Домой» — иконка как у приложения.

Через точку доступа сайт **почти не тратит мобильный трафик**: страницы и mp3 идут с компьютера на телефон напрямую.
Трафик тратят сам компьютер (обновления, облака) и голос браузера в Chrome (голоса Google). Голос Safari работает без интернета.

Если не открывается: разрешите входящие подключения для `node` (macOS спросит), проверьте брандмауэр
(на рабочем Mac он может быть включён политикой), убедитесь, что компьютер не спит, и возьмите новый адрес после переподключения.

## AI для новых тестов (Gemini и Groq)

Страница **Практика → Тесты → «🤖 Новый тест с помощью AI»**. AI каждый раз составляет новый тест (грамматика, лексика, чтение)
нужного уровня и не повторяет вопросы прошлых тестов. Сайт **строго проверяет** тест перед показом — сломанный тест не появится.

| Сервис | Роль | Где взять ключ (бесплатно) |
|---|---|---|
| **Google Gemini** | основной | https://aistudio.google.com/apikey |
| **Groq** | запасной | https://console.groq.com/keys |

**Логика выбора:**
```
если есть ключ Gemini  → тест составляет Gemini
иначе                  → Groq
если Gemini ошибся (лимит, нет сети, тест с ошибками) → Groq
если не ответил никто  → сообщение с причиной от каждого
```
Достаточно одного ключа.

**Как пользоваться на сайте (основной способ):** введите **код доступа** (выдаёт владелец сайта) → «Войти».
Ключи Gemini и Groq хранятся на сервере сайта (секреты Worker'а), браузер их не знает. Вход запоминается на год, «Выйти» — сбросить.

**Свои ключи (запасной способ, а также при локальном запуске `npm run dev`, где сервера нет)** — блок «Свои ключи»:
1. Вставьте ключ и нажмите **«Проверить ключ»** — сайт загрузит список моделей вашим ключом и сам выберет подходящую
   (Gemini — обычная «flash» самой новой версии; Groq — большая Llama). Модель можно сменить в списке.
   Названия моделей в код не зашиты: сервисы их часто меняют.
2. Выберите уровень (A2 / B1) и, по желанию, темы (например, *Present Perfect, phrasal verbs*).
3. **«✨ Создать тест»** → откроется новый тест. Он сохранится в списке «Созданные AI» (последние 20), его можно удалить.

**Безопасность ключа:** свои ключи хранятся **только в localStorage вашего браузера** — не в коде и не в git;
запрос идёт прямо из браузера, поэтому такой ключ виден в инструментах разработчика.

**Настройка сервера (владелец сайта):** панель Cloudflare → Worker → Settings → **Variables and Secrets** → Add, тип **Secret**:

| Имя | Значение |
|---|---|
| `ACCESS_CODES` | `rasul:код1, anna:код2` — имя и личный код каждого (код ≥ 12 символов; придумать: `openssl rand -hex 12`) |
| `GEMINI_API_KEY` | ключ Gemini |
| `GROQ_API_KEY` | ключ Groq (необязательно) |

Необязательно (тип Text): `GEMINI_MODEL`, `GROQ_MODEL` — модель вручную, иначе выбирается сама.
Отозвать доступ — убрать код из `ACCESS_CODES`. Локально (`npx wrangler dev`) — те же имена в файле `web/.dev.vars` (не попадает в git).
Адреса сервера: `GET /api/session`, `POST /api/login`, `POST /api/logout`, `POST /api/ai/complete` — `web/worker/api.ts`.

**Для разработчика:** адаптеры — `web/src/data/ai/aiProvider.ts` (используется и сервером), через сервер — `web/src/data/ai/serverAi.ts`, сценарий — `web/src/application/aiTests.ts`.
Чтобы добавить другой сервис (например, платный Claude через официальный SDK `@anthropic-ai/sdk`), добавьте класс
с методами `complete()` и `listModels()` и запись в `AI_SERVICES`.

## Архитектура сайта

`web/src/` устроен по принципам **clean architecture**: каждый слой зависит только от слоёв выше по списку.

| Слой | Что внутри | Зависит от |
|---|---|---|
| `domain/` | типы и чистая логика **без Vue**: интервальное повторение, текст рассказа по отметкам слов, «вставь слово», диктант, глаголы, «мои ошибки», проверка тестов, разбор теории | — |
| `data/` | хранилище (localStorage или память), загрузка контента, прогресс, адрес аудио, `ai/` — адаптеры AI | domain |
| `application/` | сценарии: очередь повторения, план на день, «мои ошибки», создание тестов с AI | domain, data |
| `presentation/` | Vue: страницы, компоненты, composables, роутер | всё выше |

```
web/src/
├── main.ts                      запуск: загрузка контента → сервисы → Vue
├── App.vue                      шапка + текущая страница (в защитной обёртке)
├── domain/
│   ├── types.ts                 типы данных (Story, GrammarTopic, Exercise, LevelTest…)
│   ├── spacedRepetition.ts      алгоритм повторения (SM-2)
│   ├── storyText.ts             текст рассказа по кускам по готовым отметкам слов
│   ├── storyTasks.ts            задание «вставьте слово»
│   ├── storyLevel.ts            уровень рассказа по номеру: 01–20 — A2, 21+ — B1

## Защита от сбоев

Если ломается одна часть, остальной сайт продолжает работать:

| Что сломалось | Что происходит |
|---|---|
| Часть страницы (плеер, текст, задания, теория, упражнения, карточка плана, настройки AI) | на её месте сообщение «временно не работает», остальное работает |
| Целая страница | сообщение на ней, другие вкладки работают |
| Один файл данных | разделы с другими данными работают |
| Браузер запретил хранилище | сайт работает, прогресс хранится в памяти до перезагрузки |
| Нет mp3 / не загрузился / сломан плеер | рассказ читает **голос браузера**, караоке работает |
| Подсветка слов | текст без подсветки |

Вверху появляется жёлтая полоска — что именно не загрузилось (нажмите, чтобы скрыть).

Устройство: компонент `SafeSection.vue` (обёртка с `onErrorCaptured`) — им обёрнута каждая страница и отдельные части.

**Проверка вручную:** добавьте `?break=<часть>` перед `#`, например
`http://localhost:5173/?break=player,markdown#/story/01_weekend_by_the_sea`.
Части: `player`, `browserReader`, `wordPopover`, `wordMarks`, `storyTasks`, `exercises`, `markdown`, страницы (`todayPage`, `storyPages`, `grammarPages`, `testsPage`, `verbsPage`…).

## Форматы файлов контента

Полное описание с примерами — в начале `tools/validate_content.py`.

### Словарь — `content/vocabulary/<LEVEL>.csv`
UTF-8 с BOM, строки CRLF, первая строка — заголовок (`表,裏,コメント,,` — формат приложения-карточек):
```
apple,яблоко,A1,,
to go out,"выходить (гулять)",A2,,
```
Глаголы — с `to`, перевод с запятой — в кавычках.

### Рассказ — `content/stories/<NN>_<slug>/`
- `story.txt` — первая строка заголовок, пустая строка, затем абзацы через одну пустую строку (каждый абзац — одной строкой).
  Предложение заканчивается на `.` `!` `?` + пробел + заглавная буква, поэтому не используйте сокращения с точкой (`e.g.`, `Mr.` → пишите `Mr`).
- `questions.json`:
  ```json
  {
    "questions": [
      {"type": "tf", "q": "Anna lives in a big house.", "answer": false, "explain": "Она живёт в маленькой квартире."},
      {"type": "choice", "q": "Why was Anna worried?", "options": ["…", "…", "…"], "answer": 0, "explain": "…"}
    ],
    "retell": ["Who is Anna?", "Where did she go?"]
  }
  ```
- `words.csv` — создаётся скриптом `find_story_words.py`.

### Тема грамматики — `content/grammar/<LEVEL>/<NN>_<slug>.json`
```json
{
  "id": "A2_05_present_perfect", "level": "A2", "order": 5,
  "title": "Present Perfect", "titleRu": "Настоящее совершённое время",
  "summary": "Одно предложение: что изучаем.",
  "theory": "## Когда используем\n…\n> I have been to London. — Я был в Лондоне.",
  "exercises": [
    {"type": "choice", "q": "She ___ a doctor.", "options": ["am", "is", "are"], "answer": 1, "explain": "…"},
    {"type": "input", "q": "I ___ (go) there yesterday.", "answer": ["went"], "explain": "…"},
    {"type": "order", "q": "Составьте вопрос", "answer": "Where do you live?", "explain": "…"}
  ]
}
```
Разметка теории: `## Заголовок`, `### Подзаголовок`, `- список`, `| таблица |`, `> English — перевод` (пример с 🔊),
`!! совет`, `⚠ ошибка → правильно`, `**жирный**`, `*курсив*`.

### Тест — `content/tests/<id>.json`
```json
{
  "id": "b1_mock_1", "kind": "mock", "title": "…", "titleRu": "…", "description": "…", "minutes": 45,
  "sections": [
    {"kind": "grammar", "title": "Грамматика", "exercises": [ … ]},
    {"kind": "reading", "title": "Чтение", "text": "English text…", "exercises": [ … ]},
    {"kind": "listening", "title": "Аудирование", "script": "Anna: …\nTom: …", "exercises": [ … ]}
  ],
  "bands": [{"min": 0, "level": "A2"}, {"min": 60, "level": "B1"}, {"min": 85, "level": "B1+"}]
}
```
`kind`: `placement` (тест уровня) или `mock` (пробный экзамен); `bands.min` — процент правильных ответов.

### Неправильные глаголы — `content/irregular_verbs.csv`
```
base,past,participle,ru,level
learn,learned/learnt,learned/learnt,учить,A1
```
Несколько вариантов формы — через `/`.

## Python-скрипты (tools/)

Запуск — из папки `EL`: `python3 tools/<скрипт>.py`.

| Скрипт | Зачем | Флаги |
|---|---|---|
| `build_site_data.py` | собирает `web/public/data/*.json` — **запускать после любых изменений** контента или аудио | — |
| `validate_content.py` | проверка грамматики, вопросов, тестов, глаголов | — |
| `find_story_words.py` | список словарных слов каждого рассказа → `words.csv` | `--force` — пересоздать все |
| `make_story_audio.py` | озвучка рассказов тремя голосами + тайминги для караоке | `--only 03`, `--voices jenny,sonia`, `--rate -10%`, `--force` |
| `make_word_audio.py` | mp3 со словами по ~100 слов | `--level A1`, `--pause 1.8`, `--rate -10%` |
| `paths.py` | **все пути проекта** — при переименовании папок меняйте только его | |
| `content.py` | чтение словарей, рассказов, грамматики (общий модуль) | |
| `story_words.py` | поиск словарных слов в тексте (все значения формы) | |
| `word_forms.py` | формы слов: *go → goes, went, gone, going* | |
| `tts.py` | озвучка через edge-tts (нейроголоса Microsoft) и работа со звуком | |

**Озвучка** нужна только для новых mp3: `pip install edge-tts` и `brew install ffmpeg`; интернет нужен только во время озвучки.
Запись одного рассказа ~1000 слов тремя голосами — несколько минут.

**Правило частей mp3 со словами:** по 100 слов; остаток ≤ 50 добавляется в последнюю часть, больше 50 — отдельная часть.

## Как добавлять и менять контент

### Новый рассказ
1. Папка `content/stories/41_my_story/` с `story.txt` и `questions.json`.
2. ```bash
   python3 tools/find_story_words.py
   python3 tools/validate_content.py
   python3 tools/build_site_data.py
   python3 tools/make_story_audio.py --only 41     # по желанию: mp3 (без него читает голос браузера)
   ```

### Новая тема грамматики или тест
Положить `content/grammar/B1/16_my_topic.json` или `content/tests/<id>.json`, затем:
```bash
python3 tools/validate_content.py && python3 tools/build_site_data.py
```

### Изменить словари
1. Отредактировать `content/vocabulary/A1.csv` (A2, B1). Перед большими правками — копия в `content/vocabulary/backup/`.
2. ```bash
   python3 tools/find_story_words.py --force   # обновить слова в рассказах
   python3 tools/build_site_data.py
   python3 tools/make_word_audio.py            # по желанию: перезаписать mp3 со словами
   ```
Прогресс повторения хранится по ключу «уровень|слово»: новые слова появятся как новые, выученные останутся выученными.

### Неправильные глаголы
Редактировать `content/irregular_verbs.csv`, затем `validate_content.py` и `build_site_data.py`.

## Деплой

Хостинг: **Cloudflare Worker со статическими файлами** — сайт и mp3 вместе. Cloudflare сам собирает сайт из GitHub при каждом push.
(Почему не Pages: Worker — основной продукт Cloudflare; на нём проще добавить посредника для AI, базу данных, задачи по расписанию.)

| Ветка | Что происходит | Адрес |
|---|---|---|
| `main` | основной сайт (`npx wrangler deploy`) | https://open-english-for-beginner.rasuli-naurizbaev.workers.dev |
| `development` и другие | предпросмотр (`npx wrangler preview`) | ссылка — в логе сборки / на странице Worker'а |

Настройки — в `web/wrangler.jsonc`: имя Worker'а (`open-english-for-beginner`, **должно совпадать с именем в Cloudflare**),
папка с файлами `./dist`, пустой блок `previews` (без него предпросмотр веток падает).

**Скрипт Worker'а** (`web/worker/`) запускается только для `/audio/*` (`run_worker_first`), всё остальное — статические файлы без кода.
Он отдаёт mp3 по частям (`Range` → `206 Partial Content`): статические файлы Worker'а всегда отдаются целиком,
а Safari на iPhone без частичной отдачи может не играть и не перематывать mp3. Логика — `worker/range.ts`, тесты — `worker/worker.test.ts`.
Запросы к mp3 считаются в лимит 100 000 запросов к коду в день.

Проверить локально на движке Cloudflare: `cd web && npm run build:pages && npx wrangler dev`, затем
`curl -I -H "Range: bytes=0-1" http://localhost:8787/audio/stories/01_weekend_by_the_sea/jenny.mp3` → `206`.

### Первая настройка (один раз, в браузере)
1. https://dash.cloudflare.com → **Workers & Pages → Create → Worker → Import a repository** → `RasuliNaurizbaev/En`.
2. Настройки:

   | Поле | Значение |
   |---|---|
   | Project (Worker) name | `open-english-for-beginner` |
   | Production branch | `main` |
   | Root directory (path) | `web` |
   | Build command | `npm run build:pages` |
   | Deploy command | `npx wrangler deploy` (по умолчанию) |
   | Non-production branch deploy command | `npx wrangler preview` (по умолчанию) |

   Версия Node берётся из `web/.node-version` (22). Переменные окружения не нужны.
3. **Deploy**. Через 1–3 минуты сайт открывается по адресу выше.

Проверить настройки локально (без входа в аккаунт): `cd web && npm run build:pages && npx wrangler deploy --dry-run`.

### Как устроена сборка
- `npm run build:pages` = `npm run build` (типы + Vite) + `scripts/copy-audio.mjs` (копирует `EL/audio` → `web/dist/audio`), затем Cloudflare выкладывает `web/dist`.
- Сайт ищет mp3 по относительному адресу `audio/…`, поэтому `VITE_AUDIO_URL` не задаётся.
- `web/public/_headers` — кеш: файлы сборки навсегда, mp3 на неделю, `data/*.json` всегда проверяются.
- Данные сайта (`web/public/data`) берутся из git — Python на Cloudflare не нужен. **После правок контента не забудьте `build_site_data.py` и закоммитить данные.**
- Хеш-адреса (`#/story/…`) не требуют настройки сервера.

### Лимиты бесплатного плана (проверено 2026-11)
- Статические файлы: до 20 000 файлов, каждый до 25 МиБ. У нас ~170 файлов, самый большой mp3 ≈ 2.5 МБ.
- Запросы к Worker'у с кодом (посредник для AI на шаге 2): 100 000 в день, 10 мс процессорного времени на запрос
  (ожидание ответа Gemini/Groq в эти 10 мс не входит).
- Актуальное: https://developers.cloudflare.com/workers/platform/limits/

### Другой вариант: mp3 в отдельном хранилище
Если mp3 станет слишком много: загрузить `audio/` в Cloudflare R2, адрес указать в `web/.env.production`
(`VITE_AUDIO_URL=…`, образец `web/.env.production.example`) и собирать обычным `npm run build`.

Локально `VITE_AUDIO_URL=/audio` (файл `web/.env.development`): Vite сам раздаёт `../audio` с поддержкой перемотки.

После деплоя по https можно добавить **PWA** — установку на телефон как приложения и работу без интернета.

## Частые проблемы

| Проблема | Решение |
|---|---|
| Сайт пустой, вверху «Не загрузилось: данные …» | `python3 tools/build_site_data.py` |
| Телефон не открывает сайт | одна сеть; разрешить входящие для `node`; брандмауэр; новый адрес после переподключения |
| Прогресс пропал | другой адрес/порт или браузер — прогресс у каждого свой; очистка данных браузера удаляет его |
| Нет звука у рассказов 21–40 | так задумано: mp3 нет, читает голос браузера (кнопка ▶ Читать вслух) |
| Голос браузера молчит | в Chrome голоса Google нужен интернет; Safari — без интернета |
| AI: «ключ не подошёл» | проверьте ключ; нажмите «Проверить ключ» |
| AI: «превышен лимит» | подождите или добавьте второй сервис (Gemini + Groq) |
| AI: «нет связи с сервисом» | нет интернета или сервис не принимает запросы из браузера — понадобится сервер-посредник |
| `npm audit` предупреждает про `picomatch` | уязвимость в инструментах сборки (ReDoS), на сайт не попадает; исправления пока нет |
| Озвучка зависла | в `tts.py` есть таймаут 60 с и повторы; просто запустите скрипт снова — готовые файлы пропускаются |
